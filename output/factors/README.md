# Factor artifacts

`legacy_manifest_stale_metrics.csv` is retained only for audit history. Its metrics
were produced before the current rolling-operator semantics and must not be used
with values generated by the current code.

`legacy_2025_development_validation.csv` is not an out-of-sample report. Factor
direction was re-selected on the 2025 window, and the window was subsequently used
in admission decisions. It is therefore a contaminated development-validation
artifact and is ineligible for model selection or final performance claims.

Run `code/revalidate_library.py` after installing the configured data and backtest
backend. Only then may `code/export_factors.py` create a current `manifest.csv`.
